# Telegram Message Sender

Скрипт для массовой рассылки сообщений в Telegram.

## ⚠️ ВАЖНО - ПРАВИЛА ИСПОЛЬЗОВАНИЯ

**Используйте этот скрипт только для:**
- Легальных целей
- Отправки сообщений пользователям, которые дали согласие
- Уведомлений в рамках вашего сервиса
- Внутренних коммуникаций

**НЕ используйте для:**
- Спама
- Нежелательных рассылок
- Нарушения правил Telegram
- Любых незаконных действий

**Последствия неправомерного использования:**
- Блокировка аккаунта Telegram
- Юридическая ответственность
- Нарушение законов о защите данных

## 📋 Требования

- Python 3.7 или выше
- Аккаунт Telegram
- API_ID и API_HASH от Telegram

## 🔧 Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Получите API_ID и API_HASH:
   - Перейдите на https://my.telegram.org/apps
   - Войдите в свой аккаунт Telegram
   - Создайте новое приложение
   - Скопируйте `api_id` и `api_hash`

3. Настройте скрипт через файл `.env`:
   
   **Способ 1:** Скопируйте файл `env_example.txt` в `.env` и заполните своими данными
   
   **Способ 2:** Создайте файл `.env` в папке проекта вручную со следующим содержимым:
   
   **Один аккаунт:**
   ```
   TELEGRAM_API_ID=ваш_api_id
   TELEGRAM_API_HASH=ваш_api_hash
   TELEGRAM_PHONE=+1234567890
   ```
   
   **Несколько аккаунтов:**
   ```
   # Первый аккаунт
   TELEGRAM_ACCOUNT_1_API_ID=api_id_1
   TELEGRAM_ACCOUNT_1_API_HASH=api_hash_1
   TELEGRAM_ACCOUNT_1_PHONE=+1234567890
   TELEGRAM_ACCOUNT_1_NAME=Account1
   TELEGRAM_ACCOUNT_1_USERS_FILE=users1.txt
   TELEGRAM_ACCOUNT_1_PROXY=socks5://user:pass@host:port
   
   # Второй аккаунт
   TELEGRAM_ACCOUNT_2_API_ID=api_id_2
   TELEGRAM_ACCOUNT_2_API_HASH=api_hash_2
   TELEGRAM_ACCOUNT_2_PHONE=+0987654321
   TELEGRAM_ACCOUNT_2_NAME=Account2
   TELEGRAM_ACCOUNT_2_USERS_FILE=users2.txt
   # TELEGRAM_ACCOUNT_2_PROXY не указан — подключение без прокси
   
   # Третий аккаунт (и так далее)
   TELEGRAM_ACCOUNT_3_API_ID=api_id_3
   TELEGRAM_ACCOUNT_3_API_HASH=api_hash_3
   TELEGRAM_ACCOUNT_3_PHONE=+1111111111
   TELEGRAM_ACCOUNT_3_NAME=Account3
   TELEGRAM_ACCOUNT_3_USERS_FILE=users3.txt
   ```
   
   **Прокси (опционально):**
   - Для каждого аккаунта можно указать свой прокси: `TELEGRAM_ACCOUNT_X_PROXY`
   - Если не указать — аккаунт подключается напрямую
   - Поддерживаемые форматы:
     - `socks5://user:pass@host:port`
     - `http://host:port`
     - `host:port:user:pass`
   - Для одного аккаунта (старый формат): `TELEGRAM_PROXY`

   **Примечание:** 
   - Для каждого аккаунта нужен отдельный файл со списком пользователей
   - По умолчанию используются файлы `users1.txt`, `users2.txt`, `users3.txt` и т.д.
   - Можно указать свой файл через `TELEGRAM_ACCOUNT_X_USERS_FILE`

## 📝 Подготовка данных

1. **Список пользователей** (для каждого аккаунта отдельный файл):
   - Для одного аккаунта: `users.txt` или файл, указанный в `TELEGRAM_USERS_FILE`
   - Для нескольких аккаунтов: `users1.txt`, `users2.txt`, `users3.txt` и т.д.
   - Или укажите свой файл через `TELEGRAM_ACCOUNT_X_USERS_FILE` в `.env`
   - По одному username на строку
   - Можно использовать `@username` или просто `username`
   - Строки, начинающиеся с `#`, игнорируются
   
   Пример `users1.txt`:
   ```
   @username1
   username2
   @username3
   ```
   
   Пример `users2.txt`:
   ```
   @username4
   username5
   @username6
   ```

2. **Текст сообщений** (`message1.txt` и `message2.txt`):
   - Два файла с текстами сообщений
   - Первое сообщение отправляется из `message1.txt`
   - Второе сообщение отправляется из `message2.txt`
   - Поддерживается многострочный текст

## 🚀 Использование

Запустите скрипт:
```bash
python telegram_sender.py
```

Скрипт:
1. Проверит наличие необходимых файлов
2. Покажет предварительный просмотр
3. Запросит подтверждение
4. Начнет рассылку с указанными задержками

**Логика рассылки:**
- Каждому пользователю отправляется **2 сообщения**
- Задержка между сообщениями для одного пользователя: **5 секунд**
- Задержка между разными пользователями: **3 секунды**
- После каждых **10 пользователей** делается пауза **10 секунд**
- **Поддержка нескольких аккаунтов:** для каждого аккаунта используется отдельный список пользователей

## ⚙️ Настройки

В файле `telegram_sender.py` можно изменить:

- `MESSAGES_PER_USER` - количество сообщений для каждого пользователя (по умолчанию: 2)
- `DELAY_BETWEEN_MESSAGES` - задержка между сообщениями для одного пользователя (по умолчанию: 5 секунд)
- `DELAY_BETWEEN_USERS` - задержка между разными пользователями (по умолчанию: 3 секунды)
- `DELAY_AFTER_EVERY_N_USERS` - после скольких пользователей делать паузу (по умолчанию: 10)
- `DELAY_AFTER_N_USERS` - длительность паузы после каждых N пользователей (по умолчанию: 10 секунд)
- `MAX_MESSAGES_PER_DAY` - максимальное количество сообщений в день (для безопасности)

## 🔒 Безопасность

- Не публикуйте `API_ID`, `API_HASH` и файл `session.session`
- Файл `session.session` содержит данные авторизации - храните его в безопасности
- Добавьте `session.session` в `.gitignore` если используете Git

## ⚠️ Ограничения Telegram

Telegram имеет ограничения на количество сообщений:
- Не более 20-30 сообщений в минуту для новых аккаунтов
- Не более 200 сообщений в день для обычных аккаунтов
- При превышении лимита аккаунт может быть заблокирован

Скрипт автоматически обрабатывает ограничения и делает паузы при необходимости.

## 🐛 Решение проблем

**Ошибка "FloodWaitError":**
- Telegram ограничил отправку сообщений
- Скрипт автоматически подождет нужное время

**Ошибка "UserPrivacyRestrictedError":**
- Пользователь ограничил получение сообщений от незнакомых людей
- Это нормально, скрипт пропустит таких пользователей

**Ошибка "PeerFloodError":**
- Превышен лимит сообщений для конкретного пользователя
- Увеличьте задержку между сообщениями
